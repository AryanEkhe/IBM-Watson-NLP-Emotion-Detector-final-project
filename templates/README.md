# Emotion Detection

## Final Project

This project implements an AI-based Emotion Detection web application using IBM Watson NLP and Flask.

## Features

- Detects anger
- Detects disgust
- Detects fear
- Detects joy
- Detects sadness
- Identifies the dominant emotion
- Flask web deployment
- Error handling
- Unit testing
- Static code analysis

## Technologies

- Python
- IBM Watson NLP
- Flask
- Requests
- Pylint
